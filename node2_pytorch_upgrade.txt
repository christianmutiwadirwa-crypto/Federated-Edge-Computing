==============================================================================
 NODE 2 — PyTorch Upgrade Instructions
 Class-Aware Federated Learning with Global Knowledge Preservation
==============================================================================

This document tells you exactly what to do on Node 2 to migrate from the
old sklearn MLP to the new PyTorch-based class-aware federated MLP.

The goal: prevent Node 2 from suppressing the 3 classes it has never seen
(ConnectionReset, DataTampering, Delay) during local training, and prevent
the tug-of-war oscillation that was observed in the sklearn baseline.

------------------------------------------------------------------------------
STEP 0: Install PyTorch
------------------------------------------------------------------------------

Run the following on the Node 2 machine (or its virtual environment):

    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

For Raspberry Pi (ARM), use the CPU-only wheel above. This is sufficient —
we are not using GPU at all.

Also confirm these existing packages are installed:
    pip install scikit-learn imbalanced-learn joblib pandas numpy

STEP 3: Understand What Changed
------------------------------------------------------------------------------

The new training script (train_node2_8classes_torch.py) does the following
during every federated round:

1. LOADS the current global model (fused_ids_model.pth) as the TEACHER.
   The teacher's parameters are frozen — it only provides soft predictions.

2. BUILDS a student model warm-started from the same global weights.

3. FREEZES the output neurons for Node 2's missing classes:
   - ConnectionResetExperiment (class index 0)
   - DataTamperingExperiment   (class index 1)
   - DelayExperiment           (class index 2)
   These neurons' gradients are set to zero before every optimiser step.
   This means Node 2 CANNOT suppress knowledge for classes it has never seen.

4. TRAINS for exactly 1 local epoch using a composite loss:
   L = L_CE  +  0.5 * L_KD  +  (0.01/2) * ||W - W_global||²
   
   L_CE   = standard cross-entropy on Node 2's 8 local classes
   L_KD   = KL divergence matching teacher's soft predictions (temperature=3.0)
   FedProx= penalises weight drift from the global baseline

5. UPLOADS weights to the FL server in the same JSON format as before.
   The FL server requires NO changes.

------------------------------------------------------------------------------
STEP 4: Run a Round
------------------------------------------------------------------------------

To participate in a federated round, Node 2 runs:

    python rpi/src/FederatedClient.py

This will:
  - Step 0: Check if global scaler exists on server. If yes, download it.
            If no (first round), fit local scaler, upload, wait for merge.
  - Step 1: Train the local PyTorch MLP (1 epoch).
  - Step 2: Extract weights in FL server format.
  - Step 3: Submit to server.
  - Step 4: Wait for FedAvg aggregation.
  - Step 5: Download global model and save as fused_ids_model.pth.
  - Step 6: Submit validation metrics.

To automate multiple rounds:
    python auto_federate.py --rounds 25 --delay 10

------------------------------------------------------------------------------
STEP 5: Verify the Setup
------------------------------------------------------------------------------

Before the first round, test that the scripts run correctly:

    cd /path/to/Federated-Learning
    python network_analysis/train_node2_8classes_torch.py --help

You should see the help text without any import errors.

Then do a full test run (without submitting to server):
    python network_analysis/train_node2_8classes_torch.py

This should print the training progress and the test accuracy on Node 2's
local data. Expect ~75-85% since Node 2's 8 classes are self-consistent.

------------------------------------------------------------------------------
EXPECTED IMPROVEMENT
------------------------------------------------------------------------------

With the sklearn baseline, the global model oscillated between 59% and 67%
across 25 rounds, never converging. The violent oscillation was caused by
both nodes suppressing each other's exclusive classes during local training.

With the PyTorch upgrade:
- Output neuron freezing prevents suppression of unseen classes.
- FedProx prevents catastrophic weight drift.
- Knowledge distillation preserves hidden-layer representations.
- 1 local epoch prevents over-fitting to local data before FedAvg.

Expected stable global accuracy: 72-82% with convergence around Round 10-15.
